AndroiOS

Run Android (LineageOS 23.2 / Android 16) on iPhone and iPad: an AArch64 virtual machine via QEMU, with Android's graphics on the Apple GPU through Metal.

View on GitHub Download IPA

Can you run Android on an iPhone?

Not natively, and not through the App Store. iOS doesn't let apps use the CPU's virtualization hardware, so an iPhone can't run Android the way a Mac runs a virtual machine. What does work is emulation: every Android instruction is translated on the fly by QEMU's just-in-time compiler.

AndroiOS does this as a sideloaded app. It boots LineageOS 23.2 (Android 16) inside the app process and renders Android's graphics on the Apple GPU. It needs two things a normal app doesn't get:

  • JIT, enabled by attaching a debugger with StikDebug. On iOS 26 and later, use StikDebug's universal.js script: on A15 and newer chips, the debugger must prepare executable memory before it can run;
  • more memory, through the increased-memory-limit and extended-virtual-addressing entitlements (GetMoreRAM, TrollStore or a paid developer profile).
Status: early alpha. LineageOS boots, renders with readable text, and responds to touch and audio in a test harness that runs the same engine code on a Mac. Version 0.2.0-alpha fixes the two device issues found so far (a dark screen at launch with JIT on iOS 26+, and SideStore's "file can't be opened" error); these fixes are awaiting confirmation on a real device.

How does AndroiOS work?

AndroiOS is a SwiftUI app that embeds QEMU as a framework and runs the virtual machine on background threads inside the app. The guest is the prebuilt LineageOS virtio_arm64only VM, which boots through UEFI and GRUB.

  • CPU: QEMU's TCG JIT translates ARM64 guest code into ARM64 host code. Its code buffer is mapped read+execute, prepared by the debugger on iOS 26+ devices with TXM (brk #0xf00d, the universal.js protocol), and written through a separate read-write alias, so it never violates iOS's W^X rules.
  • GPU: Android's OpenGL ES calls are translated to Metal and run on the Apple GPU:
Android (GLES) → Mesa virgl → virtio-gpu → QEMU
  → virglrenderer → libepoxy → ANGLE (GLES on Metal) → Apple GPU
  → IOSurface → MTKView

The GPU components are the ones UTM ships on iOS: UTM's virglrenderer and libepoxy, and WebKit's ANGLE, all at UTM's pinned versions.

  • Input: touches go to a USB tablet device that Android converts to touch; a virtual keyboard is also supported.
  • Audio: the guest's sound card feeds PCM to AVAudioEngine.
  • Network: user-mode NAT (libslirp), with no special permissions.

What performance can I expect?

Graphics are fast; CPU-bound work is slow. These numbers come from a Mac test harness running the iOS engine code, on an Apple A18 Pro GPU (the iPhone 16 Pro chip), not from a phone.

WorkloadResult
LineageOS 23.2 boot animation40–50 FPS
Boot to setup wizard~3 min (later boots), ~5 min (first boot)
glmark2 GPU benchmarkscore 103 (67–131 FPS per scene)
Android UI (apps, scrolling)well below 60 FPS: limited by CPU emulation

Expect slower results on phones (thermal throttling) and on older chips. Devices with 8 GB of RAM or M-series iPads are the realistic targets; 4 GB devices are very tight for Android 16.

How to install AndroiOS

  1. Download AndroiOS.ipa (10 MB) from GitHub Releases.
  2. Sideload it with SideStore, AltStore, TrollStore or Xcode.
  3. Apply the memory entitlements with GetMoreRAM, TrollStore, or a paid developer profile. Without them, AndroiOS gives Android less RAM.
  4. Open StikDebug and enable JIT for AndroiOS with the universal.js script.
  5. In AndroiOS's setup wizard, download LineageOS 23.2 (about 1.2 GB), then boot the VM. The first boot takes several minutes.

To build from source: clone the repository, then run Scripts/build-all.sh on a Mac with Xcode. See docs/BUILDING.md.

AndroiOS vs UTM

UTM is a mature, general-purpose virtual machine app for iOS and macOS. It runs many operating systems and supports configurations of every kind. AndroiOS is a small app focused only on Android, built on the same approach.

UTMAndroiOS
ScopeAny OS, fully configurableAndroid only, preconfigured
GPU stackvirglrenderer, libepoxy, WebKit ANGLEThe same components, at UTM's versions
Android setupImport a LineageOS VM yourselfLineageOS 23.2 bundled; one-tap setup
MaturityWidely used, stable releasesEarly alpha, not yet working on devices

If you need Android on iOS today, UTM with the LineageOS UTM VM is the more proven route. AndroiOS aims to make that experience simpler and Android-specific.
